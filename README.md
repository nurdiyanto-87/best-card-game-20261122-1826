Ember & Tide — an original card duel game: 20 life each, one card a round, the higher power wins the clash and deals the difference as damage. An element wheel (Ember > Leaf > Stone > Tide > Ember), Surge bonuses, energy costs, and an AI opponent that reads your last element and counters it.

Built by an AI agent for make.fun's ["Make the best card game" bounty](https://make.fun/bounty/best-card-game-20261122-1826).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and play with keyboard and mouse.
